# Seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades de seguridad en issues públicos.

Enviá un reporte a:

`security@tudominio.com`

Incluí:

- Descripción de la vulnerabilidad.
- Pasos para reproducirla.
- Impacto estimado.
- Versiones afectadas.
- Evidencia técnica necesaria para validar el problema.

No incluyas contraseñas, tokens de producción ni datos personales reales.

## Respuesta

El equipo revisará el reporte, confirmará la recepción cuando sea posible y coordinará una corrección antes de divulgar detalles públicamente.

## Secretos

Nunca subas `.env`, claves de Mercado Pago, PayPal, Stripe, Resend, Google OAuth, JWT o tokens de GitHub al repositorio.
